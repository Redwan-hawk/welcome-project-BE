# Welcome Project

Welcome to the backend repository for the Internship Welcome Project! This Node.js (Express) application serves as the backend for our Flutter-based logistics and shipment management application. 

## Theme & Scope
**Theme:** Logistics application, Shipment management.
**Scope:** Develop a minimum of 4 pages (including a Login page) across the team. Each person is responsible for the full-stack development (frontend UI + backend API) of 1 page.

### Technical Constraints
* **NO** Prisma Framework. Use standard database drivers/queries.
* **NO** Hashing required for this phase.


## 🚀 Getting Started

### Prerequisites
* Node.js installed
* A local database setup

### Installation
1. Clone the repository:
   ```bash
   `git clone [https://github.com/Redwan-hawk/welcome-project-BE.git](https://github.com/Redwan-hawk/welcome-project-BE.git)`

2. Navigate to the directory:
   ```bash
   `cd welcome-project-BE`

3. Install dependencies:
   ```bash
   `npm install`

4. Start the development server:
   ```bash
   `npm run dev`

## Collaboration & Git Workflow
* To ensure smooth collaboration, we strictly follow a Branching and PR strategy. Do not push directly to the main branch.
* Pull the latest code: git pull origin main
* Create a feature branch: git checkout -b feature/your-feature-name (e.g., feature/login-api or feature/shipment-crud)
* Commit your changes: Write clear, descriptive commit messages.
* Push your branch: git push origin feature/your-feature-name
* Open a Pull Request: Go to GitHub and open a PR against the main branch. Request a review from your supervisor/peers.


## Backend Requirements Reminder
1. Follow MVC Structure
2. Proper naming convention
3. Maintainability, Security and Scalability
4. API documentation: Briefly comment at the top of your controller files what the Endpoint URL is and what the expected Request Body looks like. This helps your teammates connecting the Flutter frontend.

```Good luck, and don't hesitate to ask questions!```
